# LINE 社群批次加入 V2

完全自動版本 — 切桌面不會清空,且自動點 LINE 的加入鈕。

## V2 新功能

- 🔄 **背景服務**:切回桌面也繼續跑,不會被清空
- 🟢 **浮動視窗**:倒數秒數浮在 LINE 上面,永遠看得到
- 🤖 **自動點按**:自動偵測並點選 LINE 的「建立個人檔案並加入」按鈕
- 🔔 **通知列顯示**:下拉通知欄也能看到進度
- ✅ **完成後自動回到 APP**

## 首次使用設定

開啟 APP 後,**頂部會出現橘色警告區**,點兩個按鈕分別開啟:

1. **浮動視窗權限**
   - 點按鈕 → 系統設定頁
   - 找到 「LINE 社群批次加入」 → 開啟
   - 按返回回到 APP

2. **自動點按服務 (輔助功能)**
   - 點按鈕 → 進入輔助功能設定
   - 找到 「LINE 社群批次加入」 → 點進去 → 開啟
   - 跳出警告「此服務可控制畫面」→ 同意
   - 按返回回到 APP

**只需要設定一次**,以後開 APP 都不用再做。

## 使用流程

1. 把連結貼到輸入框(每行一個)
2. 確認下方 「自動按加入鈕」 開關是開的 ✅
3. 按 **「🚀 一鍵開始」**
4. 接下來什麼都不用做!APP 會自動:
   - 開啟 LINE
   - 點「建立個人檔案並加入」
   - 等 100~300 秒(隨機)
   - 跳下一個
   - 全部跑完自動回到 APP

過程中可以做其他事,**右上角會有一個綠色浮動視窗顯示倒數秒數**,可以拖動。

## 安全提醒

- LINE 對短時間內加入大量社群有頻率限制,所以才有 100~300 秒隨機間隔
- 如果加太多會被 LINE 暫時限制功能,建議**單次不要超過 20~30 個**
- 自動點按功能基於輔助功能服務,LINE 改版時可能需要更新
